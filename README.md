# 纸上游戏厅

一个适合手机与桌面的轻量 PWA 游戏合集。每款游戏都有独立入口和安装清单，
进度只保存在当前设备，并支持离线继续。

## 游戏

- **纸上数独**：简单、中等、困难三档难度，支持草稿与智能高亮。
- **合成 1024**：使用方向键或触屏滑动合并方块，挑战抵达 1024。
- **云雀跃**：点击、触屏或按空格键穿过云门，使用原创角色和原创场景素材。

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的本地网址即可游玩。

## 检查与构建

```bash
npm run lint
npm test
```

部署产物由 `npm run build` 生成。站点托管配置位于
`.openai/hosting.json`。

## 美术与版权

`sky-hop-background.png`、`sky-lark.png` 与新版 `og.png` 为本项目生成的
原创素材。“云雀跃”没有使用 Flappy Bird 的名称、角色、管道或原始美术；
飞行与躲避障碍属于通用游戏机制。
