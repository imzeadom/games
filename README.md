# 纸上数独

一个适合手机与桌面的数独 PWA。页面采用安静的纸张风格，游戏进度保存在本地，
安装到主屏幕后也可以离线继续。

## 功能

- 简单、中等、困难三种难度
- 选中数字时，高亮同行、同列与所有相同数字
- 草稿模式支持添加或删除候选数字
- 错误提示、计时与完成统计
- 数字键、方向键、`N`、退格键等键盘操作
- 自动保存当前棋局
- PWA 安装与离线缓存

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的本地网址即可游玩。

## 检查与构建

```bash
npm run lint
npm test
```

部署产物由 `npm run build` 生成。站点托管配置位于
`.openai/hosting.json`。
