# 纸上游戏厅

一个适合手机与桌面的轻量 PWA 游戏合集。每款游戏都有独立入口和安装清单，
进度只保存在当前设备，并支持离线继续。

## 游戏

- **纸上数独**：简单、中等、困难三档难度，支持草稿与智能高亮。
- **合成 1024**：使用方向键或触屏滑动合并方块，带有清晰的方块滑移动画。
- **云雀跃**：点击、触屏或按空格键穿过云门，使用原创角色和原创场景素材。
- **暮色拾星**：在暮色林冠间自动弹跳，使用方向键移动、长按滑翔，
  通过气流救援、连击护盾与灵蝶翻倍不断刷新星分。
- **方块星阵**：把三组拼块拖进 8×8 方阵，填满横行或竖列触发消除，
  通过连消、清空奖励和可恢复的救援牌挑战高分。

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的本地网址即可游玩。

## 检查与构建

```bash
npm run lint
npm test
```

部署产物由 `npm run build` 生成。站点托管配置位于
`.openai/hosting.json`。

## 隐私与发现

游戏不接入广告、分析或营销追踪；进度使用浏览器 `localStorage` 保存，
离线文件由 Service Worker 缓存。站内的 `/privacy` 页面提供本地数据清除入口。

搜索与机器可读发现文件包括 `/sitemap.xml`、`/robots.txt`、JSON-LD
结构化数据和 `/llms.txt`。如果托管站点设置为需要登录，公开搜索引擎仍无法抓取；
需要公开访问后这些配置才会产生索引效果。
